# Task 018 - Translate Core Navigation and Layout

## Objective

Translate all core layout, navigation and shared dashboard text to Portuguese Brazil using the i18n foundation.

---

## Dependencies

Must be completed first:

- 017-i18n-foundation-pt-br

---

## Scope

Translate:

- sidebar
- top navigation
- dashboard layout
- page headers
- shared buttons
- empty states
- confirm dialogs
- table action labels
- status labels
- validation messages where shared

---

## Translation Guidelines

Use natural Brazilian Portuguese.

Examples:

```txt
Patients -> Pacientes
Membership Plans -> Planos
Benefits -> Benefícios
Subscriptions -> Assinaturas
Billing -> Pagamentos
Users -> Usuários
Dashboard -> Painel
Settings -> Configurações
Create -> Criar
Edit -> Editar
Delete -> Excluir
Cancel -> Cancelar
Reactivate -> Reativar
Deactivate -> Desativar
