# Task 062 - Shell And Layout Governance Foundation

## Objetivo

Estabelecer a estrutura espacial base do produto para que plataforma e empresa
parecam um SaaS profissional, previsivel e confiavel, independentemente de
cores e tipografia.

---

## Escopo

### 1. Shell principal

Revisar e padronizar:
- largura util das paginas;
- gutters laterais;
- espacamento entre sidebar, header e conteudo;
- altura visual do header;
- comportamento do container em desktop largo.

### 2. Hierarquia macro

Definir uma hierarquia clara entre:
- navegacao global;
- cabecalho da pagina;
- barra de contexto;
- area principal de trabalho;
- acoes secundarias.

### 3. Plataforma x empresa

Garantir que os dois workspaces compartilhem a mesma base estrutural, mas com
organizacao adequada ao contexto:
- plataforma com leitura gerencial;
- empresa com leitura operacional.

---

## Critérios de Aceite

- A estrutura do produto deixa de parecer improvisada ou inconsistente.
- Existe uma base reutilizavel para todas as proximas paginas.
- Plataforma e empresa passam a ter leitura espacial coerente.
