# Task 077 - Navigation Shell And Page Structure Rework

## Objetivo

Adequar a navegação e a estrutura base das páginas ao modelo de layout do
design Sheep.

---

## Escopo

### 1. Sidebar

Evoluir a sidebar para o comportamento previsto no guia:
- estado expandido e colapsado;
- melhor hierarquia de grupos;
- active state mais claro;
- tooltips no modo colapsado;
- consistência entre visão plataforma e empresa.

### 2. Header e contexto

Revisar header para suportar:
- contexto da área atual;
- ações rápidas com baixa fricção;
- área do usuário;
- espaço futuro para busca global e troca de workspace.

### 3. Breadcrumb e estrutura interna

Introduzir breadcrumb em telas internas e consolidar padrões de:
- largura por tipo de tela;
- separação entre módulos, workspaces e detalhes;
- uso consistente de page header.

---

## Critérios de Aceite

- O usuário entende com mais facilidade onde está e para onde pode ir.
- A navegação fica mais rasa, previsível e consistente.
- A base de layout fica pronta para detalhes em workspace e painéis laterais.
