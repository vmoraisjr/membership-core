# Task 078 - Core UI Components Sheep Variants

## Objetivo

Padronizar os componentes-base do sistema com variantes Sheep reutilizáveis,
substituindo soluções visuais oportunistas.

---

## Escopo

### 1. Button

Revisar variantes, tamanhos e estados para:
- primary;
- secondary;
- ghost;
- destructive;
- link;
- loading e disabled.

### 2. Input e campos relacionados

Padronizar:
- input;
- textarea;
- select;
- helper text;
- error text;
- label;
- foco e estados de validação.

### 3. Superfícies e feedback base

Consolidar componentes ou estilos reutilizáveis para:
- cards;
- badges de status;
- blocos de informação;
- empty states;
- alertas e feedbacks calmos.

---

## Critérios de Aceite

- Componentes-base passam a refletir o design Sheep.
- As telas reduzem dependência de `className` ad hoc.
- Os estados de ação, erro e leitura ficam mais previsíveis.
