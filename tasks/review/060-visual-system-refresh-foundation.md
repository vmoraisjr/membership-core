# Task 060 - Visual System Refresh Foundation

## Objetivo

Criar a fundacao visual da nova fase do produto, saindo do tema atual para uma
linguagem mais proprietaria e memoravel.

---

## Escopo

### 1. Direcao visual

Definir:
- paleta principal;
- tipografia;
- tokens de marca;
- estilo de cards, formularios e navegacao.

### 2. Prioridade de aplicacao

Comecar por:
- login;
- shell;
- dashboard;
- tabelas e formularios principais.

### 3. Consistencia

Introduzir variaveis e padroes reutilizaveis antes de expandir para todas as
features.

---

## Critérios de Aceite

- Existe uma base visual coesa para as proximas telas.
- O produto deixa de parecer um painel generico sem identidade.
