# Task 075 - Sheep Design Foundation And Token Alignment

## Objetivo

Alinhar a base visual do app ao design system Sheep, começando pelos tokens,
tema global e convenções semânticas.

---

## Escopo

### 1. Tokens globais

Reorganizar a base de `globals.css` para refletir:
- tokens semânticos de cor;
- tokens de spacing, radius, shadow e motion;
- preparação para light-first e dark futuro;
- nomes consistentes com o guia de design.

### 2. Mapeamento de tema

Garantir que Tailwind/Shadcn usem tokens Sheep como fonte principal, evitando
valores visuais soltos.

### 3. Base visual global

Revisar:
- background global;
- superfícies principais;
- foco visível;
- contraste;
- sombras;
- larguras máximas e shells.

---

## Critérios de Aceite

- O app passa a usar tokens Sheep como base visual.
- Reduzimos valores hardcoded em estilos globais.
- A fundação fica pronta para evolução de componentes e white-label.
