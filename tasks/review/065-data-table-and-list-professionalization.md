# Task 065 - Data Table And List Professionalization

## Objetivo

Elevar o nivel visual e operacional das tabelas e listas para que elas tenham
cara de software de gestao serio, com boa escaneabilidade e acoes claras.

---

## Escopo

### 1. Estrutura de tabela

Padronizar:
- altura de linha;
- alinhamento de colunas;
- largura de colunas sensiveis;
- tratamento de textos longos;
- posicao da coluna de acoes.

### 2. Hierarquia de informacao

Definir o que aparece como:
- dado principal;
- dado de apoio;
- status;
- metadata secundaria.

### 3. Ferramentas da lista

Reorganizar:
- busca;
- filtros;
- ordenacao;
- paginacao;
- estados vazios.

---

## Critérios de Aceite

- Listas ficam mais legiveis em uso diario.
- Acoes deixam de parecer espalhadas ou escondidas.
- O operador consegue escanear registros sem fadiga visual.
