# Task 074 - Browser Journey Automation Foundation

## Objetivo

Criar a base de automacao browser-level para validar jornadas reais da
plataforma e da empresa, alem do nivel atual de testes por service/action.

---

## Escopo

### 1. Stack de automacao

Definir a ferramenta e a arquitetura de testes de navegador.

### 2. Jornadas iniciais

Cobrir pelo menos:
- login da plataforma;
- login da empresa;
- primeiro acesso;
- abrir chamado;
- criar empresa;
- criar cliente/paciente;
- criar assinatura.

### 3. Estados visuais e interativos

Validar:
- bloqueios por permissao;
- erros de formulario;
- estados vazios;
- confirmacoes de sucesso.

---

## Critérios de Aceite

- Existe uma base real de automacao de jornada.
- Os fluxos mais importantes deixam de depender apenas de inspeção manual.
