# Sheep Color System

## 1. Filosofia de cor

A cor principal do Sheep deve transmitir confiança.

A inovação deve aparecer nos detalhes, não na cor principal.

## 2. Direção

```txt
Valor principal: Confiança
Valor secundário: Inovação silenciosa
Expressão visual: Limpa, premium e objetiva
```

## 3. Paleta principal

A cor principal recomendada é azul tecnológico.

Não deve parecer:

- Azul bancário antigo
- Azul corporativo pesado
- Azul infantil
- Azul neon

Deve parecer:

- Confiável
- Moderno
- Claro
- Preciso
- Seguro

## 4. Primary scale

```css
--blue-50:  #eff6ff;
--blue-100: #dbeafe;
--blue-200: #bfdbfe;
--blue-300: #93c5fd;
--blue-400: #60a5fa;
--blue-500: #3b82f6;
--blue-600: #2563eb;
--blue-700: #1d4ed8;
--blue-800: #1e40af;
--blue-900: #1e3a8a;
```

Uso recomendado:

```txt
Primary: blue-600
Primary hover: blue-700
Primary soft: blue-100
Focus ring: blue-600 com opacidade
```

## 5. Accent de inovação

O accent deve ser usado com moderação.

Recomendação:

```css
--violet-50:  #f5f3ff;
--violet-100: #ede9fe;
--violet-500: #8b5cf6;
--violet-600: #7c3aed;
--violet-700: #6d28d9;
```

Uso:

- Destaques pontuais
- Elementos de IA
- Recursos novos
- Insights inteligentes
- Pequenos detalhes visuais

Não usar violet como cor dominante.

## 8. Regras de uso

### Azul

Usar para:

- Ações primárias
- Links importantes
- Foco
- Estados selecionados
- Elementos de navegação ativa

### Violeta

Usar para:

- Inteligência
- Automação
- Insights
- Novidades
- Toques de inovação

### Verde

Usar apenas para sucesso, confirmação ou status positivo.

Não usar verde como cor de marca.

### Vermelho

Usar apenas para erro, risco, exclusão ou ação destrutiva.

Evitar mensagens agressivas.

### Amarelo/Laranja

Usar para aviso, pendência ou atenção moderada.

Não usar para erro crítico.

## 9. Regra de proporção

```txt
80% neutros
15% azul
5% accent/inovação/status
```

A interface do Sheep deve ser majoritariamente neutra.

Cor é orientação, não decoração.
