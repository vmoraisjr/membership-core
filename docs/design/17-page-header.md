# Sheep Page Header

## 1. Purpose

Page headers orient the user and expose the primary action for the current context.

## 2. Anatomy

```txt
Breadcrumb Optional
Title
Description Optional
Primary action Optional
Secondary actions Optional
```

## 3. Rules

- Title must be short.
- Description explains context, not obvious UI.
- Only one primary action.
- Secondary actions should not compete with primary action.

## 4. Examples

```txt
Clientes
Gerencie clientes, assinaturas e relacionamento.
[ Novo cliente ]
```

```txt
Planos
Crie e organize os planos disponíveis para assinatura.
[ Novo plano ]
```

## 5. Acceptance criteria

A page header is valid when:

- It tells where the user is.
- It clarifies the purpose of the page.
- It exposes the most important action.
- It avoids visual clutter.
