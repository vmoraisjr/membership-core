# Sheep Iconography

## 1. Biblioteca oficial

Usar:

```txt
Lucide
```

Motivos:

- Leve
- Minimalista
- Boa integração com React
- Compatível com Shadcn
- Ícones em stroke
- Aparência moderna e clara

## 2. Estilo

Ícones devem ser:

- Lineares
- Simples
- Com stroke
- Sem preenchimento
- Sem excesso de detalhe

## 3. Tamanhos

```txt
16px - metadados, inputs, badges
18px - menus compactos
20px - padrão da interface
24px - cards e ações maiores
32px - empty states pequenos
48px - empty states principais
```

Tamanho padrão:

```txt
20px
```

## 4. Stroke

Recomendado:

```txt
stroke-width: 2
```

Em áreas muito delicadas, pode usar:

```txt
stroke-width: 1.75
```

## 5. Regras de uso

- Não misturar bibliotecas.
- Não usar ícones filled.
- Não usar ícones decorativos sem função.
- Não usar ícone sozinho em ações importantes, salvo sidebar collapsed.
- Ações destrutivas devem ter ícone e texto.
- Ícones devem reforçar reconhecimento, não substituir clareza.

## 6. Exemplos de mapeamento

```txt
Home: Home
Clientes: Users
Assinaturas: BadgeCheck ou RefreshCw
Planos: Layers
Benefícios: Gift
Financeiro: CreditCard
Cobranças: Receipt
Relatórios: BarChart3
Configurações: Settings
Usuários: UserCog
Permissões: Shield
Comunicação: MessageSquare
Campanhas: Megaphone
IA/Insights: Sparkles
```

## 7. Ícone de inovação

Usar `Sparkles` com moderação.

Ele deve indicar inteligência, automação ou insight.

Não usar em excesso para não banalizar o conceito.
